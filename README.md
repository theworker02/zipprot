# zipprot

Zip digests and prot fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/zipprot/

## Install / run

```bash
git clone https://github.com/theworker02/zipprot.git
cd zipprot
node src/cli.js
node --test
```
